## Como executar

1. Certifique-se de ter o Node.js instalado.
2. Faça um clone deste repositório.
3. Abra o terminal na pasta do projeto e instale as dependências com o comando:
   `npm install`
4. Acesse o arquivo `src/utils/chaves.js` e preencha a chave da Geoapify (obtida em https://myprojects.geoapify.com) e a chave da sua licença PrimeUI.
5. Inicie a aplicação com o comando:
   `npm run dev`
6. O navegador pedirá permissão de acesso à localização.
